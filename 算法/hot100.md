## 哈希

### 两数之和

法一：哈希

1. 遍历数组。每次从哈希表中查找，是否有 target-nums[i]的元素
2. 如果有，返回结果；如果没有，插入 nums[i]并继续
3. O(log n)

```cpp
    vector<int> twoSum(vector<int>& nums, int target) {
         unordered_map<int, int> hash_map; // 数组值-数组下标
         for(int i = 0; i < nums.size(); i++){
            auto it = hash_map.find(target - nums[i]);
            if(it != hash_map.end()){
                return {i, it->second};
            }
            else{
                hash_map[nums[i]] = i;
            }
         }
        return {};
    }
```

法二：

1. 升序排序
2. 双指针指向头尾，移动，直到等于 target
3. O(n)

```cpp
    vector<int> twoSum(vector<int>& nums, int target) {
         vector<pair<int,int>> arr;
         for(int i = 0; i < nums.size(); i++){
            arr.push_back({nums[i], i});
         }
         sort(arr.begin(), arr.end(), [](const pair<int,int>& a,const pair<int,int>& b){return a.first < b.first;});
         int p1 = 0, p2 = nums.size()-1;
         while(p1 != p2){
            if(arr[p1].first + arr[p2].first == target){
                return {arr[p1].second, arr[p2].second};
            }
            else if(arr[p1].first + arr[p2].first < target){
                p1++;
            }
            else {
                p2--;
            }
         }
        return {};
    }
```

### 字母异位词分组

- 哈希，将排序后的字符串作为 key，原始字符串作为 value
- 时间复杂度：m 是字符串长度，n 是字符串数组长度，O(n \* mlogm)
- 空间复杂度：O(nm)

```cpp
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> hash;
        for(auto it : strs){
            string key = it;
            ranges::sort(key);
            hash[key].push_back(it);
        }
        vector<vector<string>> res;
        res.reserve(hash.size());
        for(auto& [_, value] : hash){
            res.push_back(value);
        }
        return res;
    }
```

### 最长连续序列

法一：哈希集合

- 将数组转换成哈希集合，遍历集合
- 当前元素为 x，如果 x-1 不在集合中，就开始统计 x 开始的连续序列长度（不断查找 x+1 是否在集合中，如果在，增加连续序列的长度）；否则继续遍历。
- 这种做法保证每次都从连续序列的最小值开始统计序列长度
- 时间复杂度：O(N)，因为二重循坏中，每个元素最多遍历两次
- 优化：假设集合中有 m 个不同元素，如果已经有一条长度大于等于 m/2 的连续序列，则不可能有第二条长度大于 m/2 的连续序列。此时可以直接返回答案

```cpp
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> hash(nums.begin(), nums.end());
        int ans = 0;
        for (auto x : hash){
            if(hash.contains(x - 1)) continue;

            int y = x + 1;
            while(hash.contains(y)){
                y++;
            }
            ans = max(ans, y - x);
            if(ans * 2 >= hash.size()) break;
        }
        return ans;

    }
```

法二：排序

- 将数组升序排序
- 用一次遍历判断连续序列长度
- O(nlogn)

```cpp
int longestConsecutive(vector<int>& nums) {
    if(nums.empty()) return 0;
    int ans = 1;
    int ret = 0;
    sort(nums.begin(), nums.end());
    int tmp = nums[0];
    for(int i = 1; i < nums.size(); i++){
        if(nums[i] - tmp == 1){
            ans++;
        }
        else if(nums[i] == nums[i - 1]){
            tmp = nums[i - 1];
            continue;
        }
        else ret = max(ret, ans), ans = 1;
        tmp = nums[i];
    }
    ret = max(ret, ans);
    return ret;
}
```

## 双指针

### 移动零

法一：双指针

- 指针 p1、p2 指向数组开头，向后移动 p2 指针，如果 p2 指向的数字为非零，交换 p1、p2 指向的数字，同时将 p1 往后移动，保证 p1 始终指向已经处理好的序列的尾部
- 时间复杂度：O(n)，其中 n 为序列长度。每个位置至多被遍历两次。

```cpp
    void moveZeroes(vector<int>& nums) {
        int p1 = 0, p2 = 0;
        while(p2 < nums.size()){
            if(nums[p2]){
                swap(nums[p1], nums[p2]);
                p1++;
            }
            p2++;
        }
    }
```

### 盛最多水的容器

双指针：

- 将 p1、p2 分别指向数组的左右边界
- 每次总是将对应元素较小的指针往中间移动
  - 原因：每次将指针向中间移动是为了找更大的容量，将指针向中间移动时，容器的宽度一定是减小的。反证法，假设我们移动对应元素较大的指针，由于短板不变甚至可能更小，且宽度也减小，所以容量一定是减小的，没有考虑的必要。
- 过程中记录最大的容量

```cpp
    int maxArea(vector<int>& height) {
        int p1 = 0, p2 = height.size() - 1;
        int ans = 0;
        while(p1 < p2) {
            ans = max(ans, (p2 - p1) * min(height[p1], height[p2]));
            if(height[p1] < height[p2]) p1++;
            else if(height[p2] < height[p1]) p2--;
            else p1++;
        }
        return ans;
    }
```

### 三数之和

> 核心：转换为两数之和，并用双指针解决两数之和，同时注意去重（跳过和上一次相等的数字）

法一：双指针

- 升序排序
- 确定一个数 x，剩下的是两数之和问题：y+z == -x
- 两数之和：双指针指向头尾元素，如果相加大于 target，右指针左移；如果小于，左指针右移
- 去重：在添加完本次循环找到的答案后进行
  - x 如果和上一个数相等，跳过
  - y、z 如果和上一个数相等，跳过
- 优化：
  - 如果 x 和紧接着的两个数相加大于 0，则之后的枚举中三数之和不可能等于 0，退出枚举
  - 如果 x 和数组末尾的两个数相加小于 0，则 x 与后面的任何数的三数之和不可能等于 0，跳过这个 x

```cpp
    vector<vector<int>> threeSum(vector<int>& nums) {
        ranges::sort(nums);
        vector<vector<int>> res;
        int n = nums.size();
        for(int i = 0; i < n - 2; i++){
            int x = nums[i];
            if(i >= 1 && nums[i - 1] == x) continue; // 去重
            // 优化
            if(x + nums[i + 1] + nums[i + 2] > 0) break;
            if(x + nums[n - 1] + nums[n - 2] < 0) continue;
            // 两数之和
            int tar = 0 - x;
            int p1 = i + 1, p2 = n - 1;
            while(p1 < p2){
                int y = nums[p1], z = nums[p2];
                if(y + z < tar){
                    p1++;
                }
                else if(y + z > tar){
                    p2--;
                }
                else{
                    res.push_back({x, y, z});
                    p1++; p2--;
                    while(nums[p1]==nums[p1-1] && p1 < p2) p1++;
                    while(nums[p2]==nums[p2+1] && p1 < p2) p2--;
                }
            }
        }
        return res;
    }
```

### 接雨水

法一：单调栈

思路：

- 维护一个严格单调递减栈，存放数组下标
- 当新来的元素大于等于栈顶元素时，开始计算能接的雨水：
  - 横着计算雨水的面积。高度为【min(新来元素，栈中第二个元素对应的数组元素) - 栈顶元素对应的数组元素】，宽度为【新来元素的下标 - 栈中第二个元素 + 1】
  - 弹出栈顶，继续判断是否满足单调栈性质
- 新元素入栈
- 时间复杂度：O(N)

```cpp
    int trap(vector<int>& height) {
        int n = height.size();
        int stk[n];
        int tt = -1;
        int res = 0;
        for(int i = 0; i < n; i++){
            if(tt == -1) {
                stk[++tt] = i;
                continue;
            }
            while(height[stk[tt]] <= height[i] && tt > 0){
                int h = min(height[i], height[stk[tt - 1]]);
                int w = i - stk[tt - 1] - 1;
                res += (h - height[stk[tt]]) * w;
                tt--;
            }
            if(height[stk[tt]] <= height[i] && tt == 0) stk[tt] = i;
            else stk[++tt] = i;
        }
        return res;
    }
```

法二：前缀后缀和

- 计算出数组的前缀和数组、后缀和数组
- 竖着计算雨水的面积。每个位置能接的水是 min(当前位置前缀， 当前位置后缀) - 当前位置高度
- 时间复杂度：O(N)
- 空间复杂度：O(N)

```cpp
    int trap(vector<int>& height) {
        int n = height.size();
        int res = 0;
        int premax[n], sufmax[n];
        for(int i = 0; i < n; i++){
            premax[i] = sufmax[i] = 0;
        }
        premax[0] = height[0];
        for(int i = 1; i < n; i++){
            premax[i] = max(premax[i - 1], height[i]);
        }
        sufmax[n - 1] = height[n - 1];
        for(int i = n - 2; i >= 0; i--){
            sufmax[i] = max(sufmax[i + 1], height[i]);
        }
        for(int i = 0; i < n; i++){
            res += min(premax[i], sufmax[i]) - height[i];
        }
        return res;
    }
```

法三：双指针

- 优化：将前缀后缀和算法的空间复杂度优化到 O(1)
-

```cpp
    int trap(vector<int>& height) {
        int n = height.size();
        int res = 0;
        int premax=height[0], sufmax=height[n-1];
        int left = 0, right = n-1;
        while(left < right){
            premax = max(premax, height[left]);
            sufmax = max(sufmax, height[right]);
            if(premax < sufmax){
                res += premax - height[left];
                left++;
            }
            else{
                res += sufmax - height[right];
                right--;
            }
        }
        return res;
    }
```

## 滑动窗口

滑动窗口算法是一种基于**双指针**的高效算法，用于解决数组或字符串中连续子序列（子串/子数组）问题。其核心思路是定义一个由左右指针 `[left, right)` 维护的“窗口”，通过扩大右边界寻找可行解，满足条件后收缩左边界优化解

### 无重复字符的最长子串

思路： 哈希

- 用一个哈希集合存储当前遍历到的无重复字符子串的头尾指针，这里称它为窗口
- 每次加入新字符时，如果窗口中已有此字符，就一直弹出头指针指向的元素，直到没有该字符为止，然后加入这个新字符
- 时间复杂度：O(n)，其中 n 为 s 的长度。

```cpp
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> hash;
        int ans = 0;
        for(int l = 0, r = 0; r < s.length(); r++){
            char c = s[r];
            while(hash.contains(c)){
                hash.erase(s[l]);
                l++;
            }
            hash.insert(c);
            ans = max(r - l + 1, ans);
        }
        return ans;
    }
```

### 找到字符串中所有字母异位词

思路：

- 窗口存放当前符合或即将符合要求的子串。
- 维护一个数组，数组下标是字母，存储该字母在目标 p 中出现的次数。
- 每次移动窗口右端点时，减少对应字母的出现次数
  - 如果为负数，说明窗口中出现了不符合要求的多余字符，移动左端点来排除多于字符
- 时间复杂度：时间复杂度：O(m+n)，其中 m 是 s 的长度，n 是 p 的长度。虽然写了个二重循环，但是内层循环中对 left 加一的总执行次数不会超过 m 次，所以滑窗的时间复杂度为 O(m)。

```cpp
    vector<int> findAnagrams(string s, string p) {
        int n = s.length();
        vector<int> ans;
        int cnt[26] = {};
        for(int i = 0; i < p.length(); i++){
            cnt[p[i] - 'a']++;
        }
        for(int l = 0, r = 0; r < n; r++){
            cnt[s[r] - 'a']--;
            while(cnt[s[r] - 'a'] < 0){
                cnt[s[l++] - 'a']++;
            }
            if(r - l + 1 == p.length()) ans.push_back(l);
        }
        return ans;
    }
```

## 动态规划

### 爬楼梯

思路：

- 状态转移方程：
  - 初始值：`dp[0] = dp[1] = 1`
  - 分类讨论：最后一次迈 1 步、最后一次迈 2 步
  - 状态转移方程：`dp[i] = dp[i - 1] + dp[i - 2]`
- 空间优化：不用数组

```cpp
    int climbStairs(int n) {
        int f1 = 1, f0 = 1;
        for(int i = 2; i <= n; i++){
            int newf = f0 + f1;
            f0 = f1;
            f1 = newf;
        }
        return f1;
    }
```

- 矩阵快速幂优化：将复杂度从 O(n)优化到 O(logn)

```cpp
class Solution {
public:
    using matrix = vector<vector<long long>>;
    matrix mul(matrix& a, matrix& b){
        int n = a.size(), m = b[0].size();
        matrix res = matrix(n, vector<long long>(m));
        for(int i = 0; i < n; i++){
            for(int k = 0; k < a[i].size(); k++){
                if(a[i][k] == 0) continue;
                for(int j = 0; j < m; j++){
                    res[i][j] += a[i][k] * b[k][j];
                }
            }
        }
        return res;
    }
    matrix mypow(matrix& x, int n, matrix& f0){
        matrix res = f0;
        while(n){
            if(n & 1){
                res = mul(x, res);
            }
            x = mul(x, x);
            n >>= 1;
        }
        return res;
    }
    int climbStairs(int n) {
        matrix f0 = {{1},{0}};
        matrix m = {{1,1},{1,0}};
        // fn = M^n * f0
        return mypow(m, n, f0)[0][0];
    }
};
```

### 打家劫舍

思路一：记忆化搜索

- 回溯三问：
  - 当前操作：枚举第 i 个房子选/不选
  - 子问题：从前 i 个房子中得到的最大金额和
  - 下一个子问题：分类讨论
    - 不选：从前 i - 1 个房子中得到的最大金额和
    - 选：从前 i - 2 个房子中得到的最大金额和
- 递归：
  - `dfs[i] = max(nums[i] + dfs(i - 2), dfs(i - 1))`
- 优化：将递归的计算结果保存下来，下次递归到同样的入参时，直接返回先前返回的结果
- 时间复杂度：O(n)

![1773898559755](image/hot100/1773898559755.png)

```cpp
    int memo[101];
    int dfs(int i, int n, vector<int>& nums){
        if(i < 0) return 0;
        if(memo[i] != -1) return memo[i];
        int choose = nums[i] + dfs(i - 2, n, nums);
        int not_choose = dfs(i - 1, n, nums);
        return memo[i] = max(choose, not_choose);
    }
    int rob(vector<int>& nums) {
        int n = nums.size();
        for(int i = 0; i < 101; i++) memo[i] = -1;
        dfs(n - 1, n, nums);
        return memo[n - 1];
    }
```

### 0-1 背包

题目：有 n 个物品，第 i 个物品的体积为 `w[i]`，价值为 `v[i]`，每个物品最多选一个，求体积和不超过背包容量 `capacity`的最大价值和

回溯三问：

- 当前操作：枚举第 `i`个物品选或不选。不选：剩余容量不变；选：剩余容量减少 `w[i]`
- 子问题：在剩余容量为 c 时，从前 `i`个物品中得到的最大价值和
- 下一个子问题：分类讨论
  - 不选：在剩余容量为 c 时，从前 `i-1`个物品中得到的最大价值和
  - 选：在剩余容量为 `c - w[i]`时，从前 `i-1`个物品中得到的最大价值和
- `dfs[i, c] = max(dfs[i - 1, c], dfs[i - 1, c - w[i]] + v[i])`

```cpp
int w[n], int v[n];
int dfs(int i, int cap){
    if(i < 0) return 0;
    if(cap < w[i]) return dfs(i - 1, cap);
    return max(dfs(i - 1, cap), dfs(i - 1, cap - w[i]) + v[i]);
}
int zero_one_knapsack( int cap){
    return dfs(n - 1, cap);
}
```

记忆化搜索版：

```cpp
int w[n], int v[n];
int memo[n][n];
int dfs(int i, int cap){
    if(i < 0) return 0;
    if(memo[i][cap] != -1) return memo[i][cap];
    if(cap < w[i]) {
        return memo[i][cap] = dfs[i - 1][cap];
    }
    return memo[i][cap] = max(dfs(i - 1, cap), dfs(i - 1, cap - w[i]) + v[i]);
}
int zero_one_knapsack(int cap){
    for(int i = 0; i < n; i++){
        for(int j = 0; j < cap; j++){
            memo[i][j] = -1;
        }
    }
    return dfs(n - 1, cap);
```

## 链表

### 回文链表

法一：栈

- 将链表的前半段压入栈
- 继续遍历链表后半段，比较每个元素和栈顶元素是否相同
- 但空间复杂度不满足 O(1)

法二：原地反转后半段链表

- 找到链表中间节点（快慢指针）
- 反转中间节点后的链表
- 比较两个链表是否相等
- 时间复杂度：O(n)
- 空间复杂度：O(1)

```cpp
class Solution {
public:
    // 找链表的中间节点
    ListNode* middleNode(ListNode* head){
        ListNode* s = head, *f = head;
        while(f && f->next){
            s = s->next;
            f = f->next->next;
        }
        return s;
    }
    bool isPalindrome(ListNode* head) {
        ListNode* cur = middleNode(head);
        // 反转链表
        ListNode* next = cur->next;
        cur->next = NULL;
        while(next){
            ListNode* tmp = next->next;
            next->next = cur;
            cur = next;
            next = tmp;
        }
        // 判断回文链表
        ListNode* head2 = cur;
        while(head2){
            if(head->val != head2->val) return false;
            head = head->next;
            head2 = head2->next;
        }
        return true;
    }
};
```

### 环形链表

#### 判断链表中是否有环

思路：快慢指针

- s 每次走一步，f 走两步，如果 s==f，则有环

#### 找出入环点

思路：floyd 判圈算法

- 设头节点到入环口需要走 a 步
- 快慢指针相遇后，再走 a 步就是入环点。
  - 即，让头指针与慢指针一起走，相遇的位置就是入环点
- 时间复杂度：O(N), 空间复杂度：O(1)

### 和为 K 的子数组

法一：前缀和

- 计算前缀和数组：`s[0] = 0, s[1] = nums[0], s[i] = s[i - 1] + nums[i - 1]`
- 双重循环，找前缀和数组之差等于目标值的即为子串
- 优化：哈希表
  - 双重循环的目标是找 `s[j] - s[i] == k`，我们可以转换成已知 `s[i]` 用哈希表找 `s[j] - k`

注意：前缀和数组长度是 `n + 1`，必须要包含一个 `s[0] = 0`，这样才能统计到 `nums[0] == k`

```cpp
    int subarraySum(vector<int>& nums, int k) {
        int n = nums.size();
        int pre[n + 1];
        pre[0] = 0; pre[1] = nums[0];
        for(int i = 2; i < n + 1; i++){
            pre[i] = pre[i - 1] + nums[i - 1];
        }
        int cnt = 0;
        unordered_map<int, int> hash;
        for(int i = 0; i < n + 1; i++){
            int tar = pre[i] - k;
            if(hash.contains(tar)){
                cnt += hash[tar];
            }
            hash[pre[i]]++;;
        }
        return cnt;
    }
```

### 滑动窗口最大值

法一：单调队列

- 维护一个长度为窗口大小、单调递减的双向队列，存储元素下标
- 每次元素从右边进入，最左边是当前最大值
  - 如果队首元素离开窗口，出队

```cpp
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> q;
        vector<int> res;
        int n = nums.size();
        for(int i = 0; i < n; i++){
            while(q.size() && nums[i] >= nums[q.back()]){
                q.pop_back();
            }
            q.push_back(i);
            while(q.front() < i + 1 - k) q.pop_front();
            if(i >= k - 1) res.push_back(nums[q.front()]);
        }
        return res;
    }
```

### 最小覆盖子串

思路：双指针

- 左右指针指向 s 头部，移动右指针，直到涵盖了 t 的所有字符
- 然后在此条件下。移动左指针
- 如果移动左指针后不能满足条件，继续移动右指针。如此往复，直到右指针达到 s 终点

```cpp
class Solution {
public:
    int ht_fin[128] = {};
    bool check(int ht[]){
        for(int i = 'A'; i <= 'Z'; i++){
            if(ht[i] < ht_fin[i]) return false;
        }
        for(int i = 'a'; i <= 'z'; i++){
            if(ht[i] < ht_fin[i]) return false;
        }
        return true;
    }
    string minWindow(string s, string t) {
        int len = s.size(), lent = t.size();
        int ht[128] = {};
        for(auto c : t){
            ht_fin[c]++;
        }
        int ans_left = 0, ans_right = INT_MAX;
        int left = 0, right = 0;
        for(;right < len; right++){
            ht[s[right]]++;
            while(left <= right && right - left + 1 >= lent && check(ht)) {
                if(ans_right - ans_left > right - left){
                    ans_left = left, ans_right = right;
                }
                ht[s[left]]--;
                left++;
            }
        }
        return ans_right == INT_MAX ? "" : s.substr(ans_left, ans_right - ans_left + 1);
    }
};
```
