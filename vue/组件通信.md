# 组件间通信

组件中的数据共有三种形式：data、props、computed。

vue 中通信方式大概可以分为父子通信，兄弟通信，跨级通信。

父子组件通信可以用：

- props
- 自定义事件
- $emit / v-on(@)
- $attrs / listeners
- $emit / ref
- .sync （双向绑定）
- v-model（双向绑定）
- $children / parent

兄弟组件通信可以用：

- EventBus（vue2）、mitt（vue3）
- Vuex/pinia(状态管理器，集中式存储管理所有组件的状态)
- $parent

跨层级（祖孙）组件通信可以用：

- provide/inject
- EventBus（vue2）、mitt（vue3）
- Vuex/pinia
- $attrs / listeners
- $root
- 路由传参
- localStorage / sessionStorage

## 前置概念：ref 和 props

### ref

ref 属性：

- 被用来给元素或子组件注册引用信息（id 的替代者）
- 应用在 html 标签上获取的是真实 DOM 元素，应用在组件标签上是组件实例对象（vc）
- 使用方式：
  1. 打标识：`<h1 ref="xxx">.....</h1>` 或 `<School ref="xxx"></School>`
  2. 获取：`this.$refs.xxx`

```js
<h1 v-text="msg" ref="title"></h1>;
<button ref="btn" @click="showDOM">点我输出上方的DOM元素</button>
<School ref="sch"/>

export default {
  name: "App",
  components: { School },
  data() {
    return {
      msg: "欢迎学习Vue！",
    };
  },
  methods: {
    showDOM() {
      console.log(this.$refs.title); //真实DOM元素
      console.log(this.$refs.btn); //真实DOM元素
      console.log(this.$refs.sch); // School组件的实例对象（VueComponent vc）
    },
  },
};
```

### props

用于父向子传递数据，只能从上一级组件传到下一级，props只读，修改会失效并warning。（但如果props传递的是函数，则子组件可以传递数据到父组件）

1. 父：传递数据：`<Demo name="xxx", :num="100"/>`
2. 子：接收数据：

   1. 第一种方式（只接收）：`props:['name'] `
   2. 第二种方式（限制类型）：`props:{name:String}`
   3. 第三种方式（限制类型、限制必要性、指定默认值）：

      ```js
      props:{
      	name:{
          type:String, //类型
          required:true, //必要性
          default:'老王' //默认值
      	}
      }
      ```

> 备注：props 是只读的，若业务需求确实需要修改，那么请复制 props 的内容到 data 中一份，然后去修改 data 中的数据

```js
export default {
  name: "Student",
  data() {
    console.log(this);
    return {
      msg: "我是一个尚硅谷的学生",
      myAge: this.age,
    };
  },
  methods: {
    updateAge() {
      this.myAge++;
    },
  },
};

props:{
  age:{
    type:Number,
    default:99 //默认值
  },
}
```

## 组件的自定义事件

子组件给父组件传递数据有两种方式：

- 父给子传递**函数类型**的 `props`
- 父给子绑定一个自定义事件
  - 第一种写法，使用 `@` 或 `v-on`
  - 第二种写法，使用 `ref`

组件的自定义事件是一种组件间通信的方式，适用于：子组件 ===> 父组件

- 使用场景：子组件 想给 父组件 传数据，那么就要在 父组件 中给 子组件 绑定自定义事件（事件的回调在 父组件 中）。

在 Vue2 里，组件实例是一个 **Vue 实例**，自带事件总线方法on、emit和off。

若想让自定义事件只能触发一次，可以使用 `once`修饰符，或 `$once`方法。

### v-on(@) / $emit

通过自定义事件，子组件用 `$emit`向父组件发送数据，父组件用 `v-on(@)` 监听并接受数据。

父组件中：`<Child @sendmsg="getChildMsg"/>` 或 `<Child v-on:sendmsg="getChildMsg"/>`，getChildMsg可以处理Child传来的数据。

子组件中：`this.$emit('sendmsg',数据)`

### ref / $emit

**ref** 作用在普通的DOM元素上，引用指向的就是该DOM元素;

**ref** 作用在子组件上，引用的指向就是子组件实例，所以父组件就可以通过 **this.$refs** 获取子组件的属性或方法，并给子组件绑定自定义事件

父组件中：

```js
<Child ref="refChild"/>
......
mounted(){
  // 获取子组件实例
  const child = this.$refs.refChild;
  // 然后监听它触发的 "send" 事件
  child.$on('send',this.handleMsg);
}
methods: {
  handleMsg(data) { // 回调函数
    console.log('收到子组件消息：', data);
  }
}
```

子组件：

```
methods:{
	sendMsg(){
		// 触发自定义事件 "send"，并传递参数
		this.$emit('send', 'hello')
	}
}
```

注意：通过 `this.$refs.xxx.$on('send',回调)`绑定自定义事件时，回调 要么配置在 methods 中，要么使用箭头函数，否则 this 指向会出问题！

解绑自定义事件： `this.$off('send')`，解绑多个事件就传入数组。

组件上也可以绑定原生 DOM 事件，需要使用 `native`修饰符。

## .sync

实现双向绑定。使用props传递时，子组件接收到数据后**可以直接修改**，并且会同时修改父组件的数据

父组件：

```js
<Child :page.sync="page"></Child>
```

子组件：

```
props:["page"]
```

## v-model

实现双向绑定，子组件通过 $emit 可以修改父组件的数据。

`v-model` 本质是  `:value` + `@input` 的组合语法糖。

父组件：

```js
<Child v-model="value"></Child>
// 等同于： 给子组件传一个value属性，监听子组件的input事件，当子组件触发this.$emit('input', 新值) 时，父组件更新它的 value
// <Child :value="value" @input="value = $event" />
```

子组件：

```js
<input :value="value" @input="handlerChange">
export default {
	props:["value"],
  methods:{
      handlerChange(e){
          this.$emit("input", e.target.value)
      }
  }
}
```

`model: { prop: '...', event: '...' }`可以用于修改默认的绑定字段名和事件名。

## $children / parent

> parent和children主要目的是作为访问组件的应急方法。子实例可以用this.$parent访问父实例，子实例被推入父实例的children数组中

`$children`：获取到一个包含所有子组件(不包含孙子组件)的 **实例对象数组**，直接拿到子组件中所有数据和方法

`$parent`：获取到一个父组件的**实例对象**，同样包含父节点中所有数据和方法

## $attrs / listeners

用于多层嵌套组件传递数据，比如父组件向孙子组件。

`$attrs`：包含父作用域里的非 props **属性集合**（class 和 style除外）。通过 this.$attrs 获取父作用域中所有符合条件的属性集合，然后还要继续传给子组件内部的其他组件，就可以通过 v-bind="attrs"

`$listeners`：包含父作用域里 .native 除外的监听**事件集合**。如果还要继续传给子组件内部的其他组件，就可以通过 v-on="$linteners"

## 依赖注入（provide / inject）

- 可以跨域多层嵌套组件向其他的组件传递数据。注意，兄弟组件之间不能传递
- 步骤：
  1. 设置依赖（provide）` provide(name, value)`
  2. 注入数据 （inject）` const value = inject(name, default)`
- 如果有多个 provide，inject 取距离该组件最近的 provide

注意：的是 **provide** 和 **inject** 传递的数据不是响应式的，也就是说用 **inject** 接收来数据后，**provide** 里的数据改变了，后代组件中的数据不会改变，除非传入的就是一个可监听的对象


## 全局事件总线（GlobalEventBus）

全局事件总线：一种组件间通信的方式，适用于 任意组件间通信。

在 main.js 中安装全局事件总线：

```js
// 创建vm
new Vue({
  el: "#app",
  render: (h) => h(App),
  beforeCreate() {
    Vue.prototype.$bus = this; // 安装全局事件总线，$bus就是当前应用的vm
  },
});
```

事件总线方法：

```js
$on(eventName, callback)
$emit(eventName, payload)
$off(eventName)
```

使用事件总线：

1. 接收数据：A 组件想接收数据，则在 A 组件中给$bus 绑定自定义事件，事件的 回调留在 A 组件自身。

   ```js
   methods(){
     handleData(data){......} // 回调
   }
   ......
   mounted() {
     this.$bus.$on('sendmsg',this.handleData) // 绑定自定义事件 xxxx
   }
   ```

2. 提供数据：`this.$bus.$emit('sendmsg',数据)`

3. 最好在 beforeDestroy 钩子中，用 `$off` 去解绑 当前组件所用到的事件。

## 消息订阅与发布（pubsub）

一种组件间通信的方式，适用于 任意组件间通信。

使用步骤：

1. 安装 pubsub：`npm i pubsub-js`
2. 引入: `import pubsub from 'pubsub-js'`
3. 接收数据：A 组件想接收数据，则在 A 组件中订阅消息，订阅的 回调留在 A 组件自身。

   ```js
   methods(){
     demo(data){......} // 回调
   }
   ......
   mounted() {
     this.pid = pubsub.subscribe('xxx',this.demo) // 订阅消息xxx
   }
   ```
4. 提供数据：`pubsub.publish('xxx',数据)`
5. 最好在 beforeDestroy 钩子中，用 `PubSub.unsubscribe(pid)`去 取消订阅

## 插槽

作用：让父组件可以向子组件指定位置插入 html 结构，也是一种组件间通信的方式，适用于 父组件 ===> 子组件。

分类：默认插槽、具名插槽、作用域插槽

使用方式：

1. 默认插槽：

   ```vue
   父组件中：
   <Category>
     <div>html结构1</div>
   </Category>
   
   子组件中：
   <template>
     <div>
       <!-- 定义插槽 -->
       <slot>插槽默认内容...</slot>
     </div>
   </template>
   ```
2. 具名插槽：

   ```vue
   父组件中：
   <Category>
       <template slot="center">
         <div>html结构1</div>
       </template>
   
       <template v-slot:footer>
          <div>html结构2</div>
       </template>
   </Category>
   
   子组件中：
   <template>
     <div>
       <!-- 定义插槽 -->
       <slot name="center">插槽默认内容...</slot>
       <slot name="footer">插槽默认内容...</slot>
     </div>
   </template>
   ```
3. 作用域插槽：子组件提供数据，父组件决定结构。

   1. 理解：数据在子组件，但根据数据生成的结构由组件的使用者（即，父组件）来决定。（games 数据在 Category 组件中，但使用数据所遍历出来的结构由 App 组件决定）
   2. 具体编码：

      ```vue
      父组件中：
      <Category>
        <!-- 接收子组件传来的数据，依据此渲染 -->
        <template scope="scopeData">
          <!-- 生成的是ul列表 -->
          <ul>
            <li v-for="g in scopeData.games" :key="g">{{g}}</li>
          </ul>
        </template>
      </Category>
      
      <Category>
        <!-- 接收子组件传来的数据，依据此渲染 -->
        <template slot-scope="scopeData">
          <!-- 生成的是h4标题 -->
          <h4 v-for="g in scopeData.games" :key="g">{{g}}</h4>
        </template>
      </Category>
      
      子组件中：
      <template>
        <div>
      		<!-- 给父组件传参 -->
          <slot :games="games"></slot> 
        </div>
      </template>
      
      <script>
      export default {
        name: "Category",
        props: ["title"],
        //数据在子组件自身
        data() {
          return {
            games: ["红色警戒", "穿越火线", "劲舞团", "超级玛丽"],
          };
        },
      };
      </script>
      ```

Vue 2.6 后用 `v-slot` 替代旧语法：

```vue
<Category v-slot="scopeData">
  <ul>
    <li v-for="g in scopeData.games" :key="g">{{ g }}</li>
  </ul>
</Category>
```

或者解构写法：

```vue
<Category v-slot="{ games }">
  <ul>
    <li v-for="g in games" :key="g">{{ g }}</li>
  </ul>
</Category>
```

## 路由传参

> 通过路由带参数进行传参，A组件通过路由跳转到B组件(带参数传值)，传参方式可划分params传参和query传参

1. params传参 接收用 `this.$route.params.id`
2. query传参 用 `this.$route.query.id`

## localStorage / sessionStorage

> 通过SessionStorage(程序退出销毁)、LocalStorage(长期保存)缓存的get,set方法进行传递;
>
> 注意：`JSON.parse()` / `JSON.stringify()` 做数据格式转换

获取数据 ：`window.localStorage.getItem(key)`

存储数据：`window.localStorage.setItem(key,value)`

# vue3的组件通信

Vue3移除了listeners，用pinia替换vuex，用mitt替换全局总线bus

## props

**父组件将数据传递给子组件，子组件通过props属性接收父组件传递的数据。**

子组件：

```ts
<script setup>
  // 使用 defineProps 函数来定义 Props 的类型和默认值
  const props = defineProps({
    // 变量 count 是通过父组件传递过来的
    count: {
      type: Number,
      default: 0
    }
  })
</script>
<template>
  <div id="child">
    <h1>count: {{ count }}</h1>
  </div>
</template>
```

父组件：

```ts
<script setup>
  import { ref } from 'vue';
  import Child from './Child.vue';

  // 使用 ref 函数创建了一个响应式的变量 count，初始值为 0，该变量将用于传递给子组件
  let count = ref(0)
</script>

<template>
  <div id="parent">
    <!-- 将 count 变量传递给子组件 Child -->
    <Child :count="count"/>
  </div>
</template>
```

## $emit

**子组件通过 $emit 方法触发一个自定义事件，并传递需要的参数。父组件通过在子组件上监听对应的事件，并指定触发事件时的回调函数。**

子组件：

```vue
<script setup>
  const props = defineProps({
    count: {
      type: Number,
      default: 0
    }
  })

  // 使用 defineEmits 函数定义了一个名为 changeParentCount 的自定义事件。
  const emit = defineEmits(['changeParentCount'])
  const changeParentCount = () => {
    // 通过 emit 方法触发名为 changeParentCount 的自定义事件，并将参数 5 传递给父组件。
    emit('changeParentCount', 5)
  }

</script>

<template>
  <div id="child">
    <h1>count: {{ count }}</h1>
    <button @click="changeParentCount">更新父组件的count</button>
  </div>
</template>
```

父组件：通过 @ 符号监听子组件自定义事件 changeParentCount，并在父组件中执行名为 changeParentCount 的方法

```vue
<Child :count="count" @changeParentCount="changeParentCount">
```

## ref 和 defineExpose

**在 Vue3 中，ref 函数除了可以用于定义一个响应式的变量或引用之外，还可以获取DOM组件实例。**

**而 defineExpose 是用于将组件内部的属性和方法暴露给父组件或其他组件使用。通过这种方式，我们可以定义哪些部分可以从组件的外部访问和调用。**

## mitt

在 Vue 3 中，可以使用第三方库 mitt 实现组件之间的通信。**mitt 是一个简单且强大的事件总线库（类似于 Vue 2 中的EventBus），它提供了一种方便的方式来在不同组件之间传递事件和数据。**
