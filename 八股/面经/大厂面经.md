### 学校里学了哪些课

### int有几个字节，为什么

32/64位系统：4字节

32位CPU一次可以处理32位（4字节）数据。当 int 的大小与CPU寄存器和数据总线宽度一致时，内存访问和对齐最自然，执行效率最高。

64位系统中，许多编译器仍保持 int 为4字节，是为了兼容32位，以避免破坏旧代码的假设（如结构体大小、文件格式），并且节省内存。long 或 long long 则用于64位需求。

16位系统，int通常是2个字节。

### 堆和栈是什么，有什么区别

内存模型：

- 栈：先进后出，读取速度快，内存有限，由系统自动管理，存放局部变量、函数参数、返回地址。
- 堆：动态分配，手动或GC管理，空间大，存取速度较慢，内存管理算法

JavaScript 中的堆与栈

- 基本类型 → 栈 （number string boolean null undefined symbol bigint）
- 引用类型 → 堆 （object array function ）
  - 栈里只存一个指向堆的引用（内存地址）

### js的数组和其他语言有什么区别

C：固定长度、元素类型相同、内存连续、索引为正数

JS：一个特殊的对象，包含length属性，元素类型可以不同，可以是稀疏数组，访问时使用哈希，索引为字符串key

JS 的TypedArray = 真正的连续内存数组

### 如何判断变量是不是数组

- Array.isArray()
- arr instanceof Array
- Object.prototype.toString.call(arr).slice(8, -1)
- arr.constructor === Array

### instanceof用法

判断左侧的对象是否是右侧类/构造函数的实例。检测构造函数 B 的 prototype 属性是否出现在对象 A 的原型链上。

### js函数使用值传递还是引用传递，怎么判断，如何避免引用传递影响外部变量，怎么深拷贝

```
JS 参数传递
└── 永远是值传递
    ├── 基本类型  → 传值的副本，函数内怎么改都不影响外部
    └── 引用类型  → 传地址的副本
        ├── 重新赋值参数  → 不影响外部
        └── 修改属性/元素 → 影响外部（共享堆内存）

避免影响外部
├── 浅拷贝（{...obj}）→ 只有一层嵌套时够用
└── 深拷贝           → 嵌套结构必须用
```

### 0.1+0.2为什么不等于0.3，怎么避免这种情况

浮点数运算的精准度丢失。

JS中的值以二进制存储，最多存储64位

0.1转为二进制：无限循环位，所以存储时舍弃了一些值

- toFixed保留小数位数
- 扩大系数法（乘以一个系数变为整数后相加，再将结果除以系数）

### 输入url到页面显示经过了哪些步骤，js执行会不会阻塞html渲染吗

JS执行会阻塞HTML渲染。 浏览器引擎中负责解析HTML的GUI渲染线程与执行JS的JS引擎线程是互斥的，**JS执行时会暂停DOM树的构建，从而阻塞页面渲染**。为了避免阻塞，可将脚本放在页面底部，或使用 async / defer 属性。

CSS也会阻塞渲染，但不会阻塞DOM解析

### 常见的宏任务和微任务有哪些，执行的顺序

同步代码 -> 微任务 -> 宏任务。每次执行完一个宏任务后，都会去清空微任务队列。UI 渲染 会在微任务队列清空后执行渲染。

微：promise的方法then catch finally、mutationObserver、nextTick
宏：script、setTImeout、setTimeInterval、IO、UI渲染、setImmidiate

### 如果想在页面上渲染十万条数据，有什么好方法，虚拟列表是怎么实现的

虚拟列表：

- 外部容器固定高度并设置 overflow: auto。
- 内部包含一个代表全部数据高度的占位元素。

将10万条数据分组， 在浏览器刷新间隔（16.7ms）分批次渲染。
